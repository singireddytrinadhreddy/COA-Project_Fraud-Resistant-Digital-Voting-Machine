# Fraud-Resistant Digital Voting Machine (COA Project)

A Computer Organization and Architecture (COA) project implementing a fraud-resistant digital voting machine using **Logisim-evolution**.

## Project Files
- `25CSB1A27_SingireddyTrinadhReddy_COA.circ`: Main circuit design file for Logisim-evolution (v4.1.0+).

## How to Run
1. Download and install [Logisim-evolution](https://github.com/logisim-evolution/logisim-evolution).
2. Open `25CSB1A27_SingireddyTrinadhReddy_COA.circ` in Logisim-evolution.
3. Enable simulation to test the voting machine logic and anti-fraud verification mechanisms.
